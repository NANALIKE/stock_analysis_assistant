## 目标与范围

通过免费数据源采集、标准化、校验和发布 A 股日行情，供本地单用户查询可追溯的数据版本。

一期只提供行情生成与查询。历史目标从 2000 年起；当前实现覆盖沪深 A 股及历史退市股，北交所属于来源缺口。预测、公司事实、问答、分钟行情和真实交易不属于本能力的一期范围。

## 使用流程与输入输出

1. 调用方通过 API 或 CLI 提交指定交易日的日更任务，或指定日期区间的历史补采任务；可选证券代码用于抽样和修复。
2. 系统返回任务 ID，异步同步证券与交易日、采集行情、标准化并执行质量校验。
3. 调用方通过任务状态接口观察进度、结果与失败原因；失败时可显式重试。
4. 合格数据发布为活动版本；调用方按代码/名称搜索证券，并按日期范围查询日线。

查询结果包含证券、数据版本、数据截止时间、来源、复权口径、日线和逐日状态；字段定义以[一期日行情数据模型](../../architecture/market-data-model.md)和 [API 契约](../../../api/openapi.yaml)为准。

## 业务规则

- 当前日更和历史补采均由 API/CLI 手动触发，尚无自动日更调度。
- 相同规范化生成请求复用既有任务 ID；失败重试保留任务 ID 并递增执行次数。
- 同步全部 18 个 BaoStock 日 K 字段，保存逐日状态、复权因子和完整分红记录。
- 默认查询本地生成的前复权 `qfq`；显式指定 `none` 返回不复权日线。复权只作用于 OHLC，成交额等其他字段保持其来源口径。
- 有效行情完整率门禁为 99.5%；完整率依据证券和交易日基准计算，不将停牌、未上市和已退市静默当作正常行情填充。
- 查询只读取活动逻辑版本及其声明继承的历史分区。校验失败或采集中的数据不得覆盖已发布数据。
- 原始响应、采集上下文、检查点和来源审计用于失败恢复与重放。

## 异常行为

数据源、Worker 或质量校验失败时，任务明确失败，上一活动版本继续可查。进程重启后继续处理 queued 任务，将 running 任务及其执行记录标记为失败，未完成 building 版本标记为 rejected；失败任务由调用方显式重试。尚无活动版本时，查询返回明确错误。

## 验收标准与当前验证范围

一期要求生成请求异步受理、任务可观察且幂等可恢复、查询不读取半成品、本地复权可核对、逐日缺失可分类，并达到交易日 18:00 数据与 99.5% 有效行情完整率目标。

当前已完成离线闭环与有限在线样本验证；未完成全市场多年代下载，也不能据此宣称持续满足全市场 18:00 新鲜度目标。实际证据与未验证范围以[采集验收](../../development/baostock-acceptance.md)为准。
